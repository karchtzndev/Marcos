═══════════════════════════════════════════════════════════
ATIVANDO A SEGURANÇA — PASSO A PASSO NO COMPUTADOR
═══════════════════════════════════════════════════════════

Tempo estimado: 20 a 30 minutos.

⚠️ ANTES DE COMEÇAR:
   • Faça isso com a loja FECHADA. O sistema fica alguns
     minutos fora do ar no meio do processo.
   • Abra o painel Gerencial atual → aba Loja → clique em
     "Baixar backup". Guarde esse arquivo.


═══════════════════════════════════════════════════════════
PARTE 1 — FIREBASE (10 minutos)
═══════════════════════════════════════════════════════════

───────────────────────────────────────────────────────────
PASSO 1 — LIGAR O LOGIN POR E-MAIL
───────────────────────────────────────────────────────────

1. Abra  console.firebase.google.com  no navegador
2. Clique no projeto "omarkin-burguer-39bda"
3. No menu da ESQUERDA, procure a seção "Criação" / "Build"
   e clique em "Authentication"
4. Clique no botão "Vamos começar" / "Get started"
5. Vai abrir uma lista chamada "Provedores de login".
   Clique em "E-mail/senha" (o primeiro da lista)
6. Vai abrir um painel. Ligue a PRIMEIRA chave (Ativar/Enable)
   → NÃO precisa ligar a segunda ("Link de e-mail")
7. Clique em "Salvar"


───────────────────────────────────────────────────────────
PASSO 2 — CRIAR SUA CONTA DE GERENTE
───────────────────────────────────────────────────────────

1. Ainda em Authentication, clique na aba "Users" / "Usuários"
   (fica no topo da página)
2. Clique no botão "Adicionar usuário"
3. Preencha:
   • E-mail: use um e-mail REAL que você acessa
             (é por ele que você recupera a senha)
   • Senha: mínimo 6 caracteres — use uma senha forte
4. Clique em "Adicionar usuário"
5. Seu e-mail vai aparecer na tabela. Na coluna da DIREITA
   tem "Identificador do usuário (UID)" com um código tipo:
   aB3xK9mP2qR7sT1vW4yZ8...
6. Passe o mouse em cima do UID → aparece um ícone de copiar.
   CLIQUE PARA COPIAR.
7. Cole esse UID no Bloco de Notas — você vai usar agora.


───────────────────────────────────────────────────────────
PASSO 3 — DAR PERMISSÃO DE GERENTE PRA SUA CONTA
───────────────────────────────────────────────────────────

1. No menu da ESQUERDA, clique em "Firestore Database"
2. Clique em "+ Iniciar coleção" (acima da lista de coleções,
   no primeiro painel da esquerda)
3. Em "ID da coleção", digite exatamente:

       users

   (minúsculo, sem acento, no plural)

4. Clique em "Avançar" / "Next"
5. Em "ID do documento", COLE O UID que você copiou
   ⚠️ NÃO clique em "Automático" — tem que ser o UID exato
6. Adicione os campos. Para cada um, clique em
   "+ Adicionar campo":

   ┌─────────┬──────────┬─────────────────────┐
   │ Campo   │ Tipo     │ Valor               │
   ├─────────┼──────────┼─────────────────────┤
   │ name    │ string   │ Seu Nome            │
   │ email   │ string   │ seu@email.com       │
   │ role    │ string   │ gerente             │
   │ active  │ boolean  │ true                │
   └─────────┴──────────┴─────────────────────┘

   ⚠️ ATENÇÃO NOS DOIS ÚLTIMOS:
      • "role" → valor exatamente: gerente
        (minúsculo, sem acento, sem espaço sobrando)
      • "active" → mude o TIPO para "boolean" no menu
        suspenso e escolha "true". Não digite a palavra
        true como texto — o tipo tem que ser boolean.

7. Clique em "Salvar"

CONFIRA: deve aparecer uma coleção "users" com um documento
dentro e os 4 campos listados.


───────────────────────────────────────────────────────────
PASSO 4 — PUBLICAR AS REGRAS DE SEGURANÇA
───────────────────────────────────────────────────────────

1. Ainda em Firestore Database, clique na aba "Regras"
   (no topo, ao lado de "Dados")
2. Clique dentro do editor e APAGUE TUDO
   (Ctrl+A e Delete — no Mac, Cmd+A)
3. Abra o arquivo FIRESTORE-REGRAS.txt
4. Copie TODO o bloco de regras — começa em
   "rules_version = '2';" e termina no último "}"
5. Cole no editor do Firebase
6. Clique em "Publicar"

───────────────────────────────────────────────────────────
PASSO 6 — SUBIR OS ARQUIVOS NOVOS
───────────────────────────────────────────────────────────

1. No computador, descompacte omarkin-pwa-apps.zip

═══════════════════════════════════════════════════════════
SE ALGO DER ERRADO
═══════════════════════════════════════════════════════════

▸ "Sua conta não tem permissão de acesso"
  O documento users/{seu-uid} não existe ou o UID está errado.
  Volte no PASSO 3 e confira se o ID do documento é exatamente
  igual ao UID que aparece em Authentication → Users.

▸ Login aceita mas o painel fica em branco
  O campo "role" ou "active" está errado. Em Firestore →
  users → seu documento, confira:
  role = gerente (string)  |  active = true (boolean)

▸ "Missing or insufficient permissions"
  As regras não foram publicadas. Refaça o PASSO 4.

▸ O site abre mas o cardápio não carrega
  As regras já estão publicadas mas os arquivos novos ainda
  não subiram. Confira o PASSO 6.

▸ Esqueceu a senha
  Na tela de login clique em "Esqueci minha senha".

▸ Precisa destravar tudo com urgência
  Em Firestore → Regras, substitua tudo por:

      rules_version = '2';
      service cloud.firestore {
        match /databases/{database}/documents {
          match /{document=**} { allow read, write: if true; }
        }
      }

  Isso reabre o banco (INSEGURO — use só pra destravar e
  depois republique as regras corretas).
